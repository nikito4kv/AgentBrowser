# Spec: Улучшение восприятия и устойчивости (Contextual Vision & Recovery)

## 1. Цель
Сделать агента автономным и устойчивым к ошибкам навигации и перегрузке контекста. Агент должен понимать, *что* он видит (а не только *где*), уметь восстанавливаться после сбоев API и работать с большими страницами без зависаний.

## 2. Contextual Vision (SoM 2.0)
### 2.1. Сбор семантики
-   JS-скрипт `annotate.js` должен не только рисовать метки, но и собирать JSON-структуру:
    ```json
    [
      {"id": 1, "tag": "button", "text": "Поиск", "aria-label": "Google Search"},
      {"id": 2, "tag": "input", "placeholder": "Введите запрос"}
    ]
    ```
-   Этот список передается модели в текстовом виде вместе со скриншотом. Модель сможет сопоставить "Кнопка 1" с "Кнопка Поиск".

## 3. Self-Healing & Recovery
### 3.1. Обработка пустых ответов
-   В `main.py`: Если `response.candidates` пуст:
    1.  Не падать.
    2.  Удалить последнее сообщение пользователя из истории (сбойный запрос).
    3.  Отправить системное сообщение: "Предыдущий запрос вызвал ошибку API. Попробуй другое действие или упрости задачу."
    4.  Если сбой повторяется 2 раза подряд — только тогда просить помощи.

## 4. Content Optimization
### 4.1. Truncate Content
-   В `BrowserManager.extract_content`:
    -   Обрезать результат `markdownify` до N символов (например, 10 000).
    -   Добавлять пометку `...[Контент обрезан]...` в конце.
    -   Удалять лишние пустые строки.

## 5. Ожидаемый результат
Агент сможет пройти сценарий "Найди информацию о Роналду" и "Найди репозиторий на GitHub" без падений, корректно выбирая элементы и обрабатывая текст.
