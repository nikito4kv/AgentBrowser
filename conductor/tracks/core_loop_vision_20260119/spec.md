# Spec: Разработка ядра автономного агента (Core Loop & Vision)

## 1. Цель
Реализовать базовую архитектуру автономного ИИ-агента, способного управлять браузером через визуальный анализ (Vision) и динамическую разметку элементов (Set-of-Mark).

## 2. Ключевые компоненты

### 2.1. Browser Controller (Playwright)
- Инициализация браузера (Chromium) с использованием `user_data_dir` для сохранения сессий.
- Навигация по URL.
- Снятие скриншотов страницы.

### 2.2. Visual Annotator (Set-of-Mark)
- JS-скрипт, внедряемый на страницу для поиска интерактивных элементов (`a`, `button`, `input`, `textarea`, `select`).
- Фильтрация видимых элементов.
- Присвоение уникальных числовых ID (`data-agent-id`) и отрисовка визуальных меток (лейблов) поверх элементов.

### 2.3. Agent Logic Layer (Gemini 2.0 Flash)
- Использование `google-genai` SDK.
- Системный промпт, описывающий роль агента и доступные инструменты.
- Обработка скриншота с разметкой и принятие решения о следующем шаге.

### 2.4. Action Layer (Tools)
- `click_element(label_id: int)`: Находит элемент по `data-agent-id` и выполняет клик.
- `type_text(label_id: int, text: str)`: Ввод текста в поле.
- `scroll(direction: str)`: Прокрутка страницы.
- `task_completed(result: str)`: Завершение задачи.

## 3. Пользовательский сценарий (User Flow)
1. Пользователь запускает агента с текстовым запросом.
2. Агент открывает браузер.
3. Цикл (Loop):
    - Снимает скриншот с разметкой.
    - Отправляет в Gemini.
    - Gemini возвращает вызов инструмента.
    - Агент выполняет действие в Playwright.
    - Повторяет до завершения.

## 4. Требования к реализации
- Язык: Python 3.10+.
- Менеджер пакетов: `uv`.
- Логирование действий в терминале с использованием цветов (библиотека `rich`).
- Обработка ошибок: retry-механизм (3 попытки) перед запросом помощи у пользователя.
