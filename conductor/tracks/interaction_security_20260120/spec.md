# Specification: Interaction & Security

## Обзор
Этот трек направлен на превращение агента из "черного ящика" в интерактивного помощника. Мы добавим возможность запрашивать обратную связь у пользователя (`ask_user`), корректно признавать поражение (`task_failed`) и безопасно выполнять критические действия (Security Layer).

## Проблематика
1.  **Отсутствие диалога:** Агент не может уточнить детали (например, "Вам подходит этот отель?").
2.  **Риск:** Агент может случайно удалить письма или оформить заказ без подтверждения.
3.  **Тупики:** Если агент не может решить задачу, он зацикливается, так как нет способа "сдаться".
4.  **Слепота к деталям:** Агент кликает по ссылкам, не зная URL (риск фишинга или ухода с сайта).

## Требования

### 1. Новые Инструменты (Tools)
*   `ask_user(question: str) -> str`:
    *   Приостанавливает выполнение.
    *   Выводит вопрос в консоль (stdout).
    *   Ждет ввода от пользователя (stdin).
    *   Возвращает ответ пользователя в модель.
*   `task_failed(reason: str)`:
    *   Завершает цикл выполнения с ошибкой.
    *   Выводит причину в консоль.
*   `get_element_details(label_id: int) -> dict`:
    *   Возвращает атрибуты элемента: `href`, `title`, `alt`, `text`, `src`.
    *   Позволяет проверить ссылку перед переходом.

### 2. Security Layer (Системный Промпт)
*   Модификация `system_instruction`:
    *   Добавить правило: "Если действие необратимо (удаление, покупка, отправка письма) -> СНАЧАЛА спроси пользователя через `ask_user`".
    *   Добавить правило: "Если не уверен в выборе -> спроси пользователя".

### 3. Интеграция в Main Loop
*   Обновить `Orchestrator` (`main.py`) для обработки новых типов ответов от инструментов (особенно интерактивного ввода).

## Сценарии использования (Use Cases)

### UC1: Удаление Спама (Security)
1.  Агент находит 5 писем.
2.  Агент: "Я нашел 5 подозрительных писем. Удалить их?" (`ask_user`).
3.  Пользователь: "Да".
4.  Агент удаляет письма.

### UC2: Уточнение (Interaction)
1.  Агент ищет вакансии.
2.  Агент: "Нашел вакансию Python Dev. Зарплата не указана. Откликаться?" (`ask_user`).
3.  Пользователь: "Нет, ищи дальше".
4.  Агент продолжает поиск.

### UC3: Тупик (Failure)
1.  Агент пытается зайти на сайт, но там капча.
2.  Агент пробует 2 раза, не выходит.
3.  Агент: `task_failed("Обнаружена непреодолимая капча")`.
4.  Программа завершается.
