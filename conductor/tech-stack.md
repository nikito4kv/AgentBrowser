# Технологический стек AgentBrowser

## Язык программирования
*   **Python 3.10+**: Основной язык разработки.

## AI и ML
*   **Модель:** Gemini 2.0 Flash.
*   **SDK:** `google-genai` (новый официальный SDK от Google для работы с GenAI).

## Браузерная автоматизация
*   **Playwright (Python):** Для управления браузером, эмуляции действий и снятия скриншотов.
*   **playwright-stealth:** Библиотека для маскировки автоматизации и обхода анти-бот систем.

## Управление проектом и зависимостями
*   **uv:** Инструмент для управления виртуальным окружением и быстрой установки зависимостей.

## Вспомогательные библиотеки
*   **Pillow (PIL):** Обработка и оптимизация скриншотов перед отправкой в модель (изменение размера, сжатие).
*   **python-dotenv:** Управление переменными окружения (хранение API ключей).
*   **Rich:** Для создания красивого и цветного вывода в терминале (согласно руководству по продукту).

## Инфраструктура
*   **User Data Directory:** Использование постоянного профиля браузера в Playwright для сохранения сессий (логинов в сервисах).
