# Spec: Расширение инструментов навигации (Smart Navigation & Scraping)

## 1. Цель
Расширить набор инструментов агента, добавив возможность прямого управления адресной строкой, историей браузера и извлечения текстового контента. Научить агента самостоятельно определять, когда нужно использовать поиск, а когда — прямой переход.

## 2. Новые инструменты
### 2.1. Navigation Tools
-   `navigate(url: str)`: Переход по указанному URL.
-   `go_back()`: Эмуляция кнопки "Назад".
-   `go_forward()`: Эмуляция кнопки "Вперед".
-   `reload()`: Перезагрузка страницы.

### 2.2. Content Tools
-   `extract_content()`: Извлекает основной текст страницы (полезно для суммаризации или ответа на вопросы). Возвращает текст в формате Markdown.

## 3. Логика (Smart Routing)
-   Обновление системного промпта: Добавить инструкции, объясняющие, что если пользователь дает URL или домен (например, "open youtube.com"), нужно использовать `navigate`. Если запрос абстрактный ("найди рецепт"), использовать поиск (текущий флоу).

## 4. Технические детали
-   **URL Validation:** Простая проверка, является ли строка URL (начинается с http/https или выглядит как домен).
-   **Markdown Conversion:** Использовать библиотеку (например, `markdownify` или встроенные средства), чтобы превращать HTML в читаемый текст для модели.
