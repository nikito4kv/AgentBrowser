# AgentBrowser: Автономный AI-агент для управления браузером

## Обзор продукта
AgentBrowser — это консольное приложение (CLI), предназначенное для автоматизации рутинных задач в веб-браузере с использованием возможностей мультимодальной модели Gemini 2.0 Flash. Проект ориентирован на опытных пользователей, стремящихся повысить свою продуктивность за счет делегирования многошаговых веб-операций интеллектуальному агенту.

## Основная цель
Автоматизация повторяющихся процессов в вебе для повышения личной продуктивности пользователя, устраняя необходимость ручного взаимодействия со сложными или динамическими интерфейсами.

## Целевая аудитория
*   **Опытные пользователи:** Те, кто предпочитает работу в терминале и хочет автоматизировать свои повседневные задачи в интернете.

## Ключевые функции
*   **Автономная навигация и самовосстановление:** Самостоятельное выполнение действий с механизмом автоматического восстановления после сбоев API.
    *   **Надежность взаимодействия:** Использование каскадных стратегий и контекстной разметки элементов (Semantic SoM) для безошибочного выбора кнопок и полей.
*   **Проактивное планирование (Chain-of-Thought):** Агент умеет разбивать сложные задачи на последовательные шаги и отслеживать их выполнение.
*   **Краткосрочная память:** Сохранение важных фактов и данных в течение сессии для использования в последующих шагах.
*   **Умное извлечение данных (Scraping):** Способность извлекать и оптимизировать текстовое содержимое страниц для работы с большими объемами информации.
*   **Визуальный анализ (Vision):** Агент «видит» интерфейс страницы, распознает интерактивные элементы и понимает контекст без использования жестко заданных селекторов.
*   **Интерактивное выполнение (Security Layer):** Агент запрашивает подтверждение пользователя перед совершением критических действий (например, удаление данных или совершение оплаты).

## Решаемые проблемы
*   **Сложность автоматизации:** Устранение высокого порога входа (не требуется знание HTML/DOM для настройки скриптов).
*   **Динамические интерфейсы:** Решение проблемы «хрупких» селекторов — агент адаптируется к изменениям дизайна сайтов так же, как человек.
